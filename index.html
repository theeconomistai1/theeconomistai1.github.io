shorts-factory-app

A personal publishing tool for three YouTube channels.

shorts-factory-app is a private tool that runs on its owner's own computer. It uploads original short videos, made from scratch by the owner, to the owner's own YouTube channels and schedules when they go public:

  • Beta Kids: gentle 2D animated lessons for young children
  • For Some Reason Satisfying: 3D animated satisfying loops
  • The Economist AI: whiteboard explainers on personal finance

How it uses YouTube

The tool uses the YouTube Data API to upload a video and set its scheduled publish time, and to confirm that it is signed in to the correct channel before uploading. Every video is watched and approved by the owner before it is uploaded. The tool is not offered to the public and does not access anyone else's account.

Uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy.
